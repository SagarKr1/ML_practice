# 💼 Machine Learning Problem: Salary Prediction System

## 📌 Objective

Build a Machine Learning model that can **predict the salary of an employee** based on multiple input features.

---

## 📊 Dataset Description

The dataset contains the following columns:

| Feature Name      | Description                              |
| ----------------- | ---------------------------------------- |
| YearsExperience   | Number of years of experience            |
| ProjectsCompleted | Total number of projects completed       |
| SkillScore        | Skill rating out of 100                  |
| Salary            | Salary of the employee (Target Variable) |

---

## 🎯 Goal

Your task is to:

* Build a **Multiple Linear Regression model**
* Predict the **Salary** based on:

  * Years of Experience
  * Projects Completed
  * Skill Score
