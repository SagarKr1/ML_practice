# 🧠 Machine Learning Practice Problem (Classification)

## 📌 Problem Title:
Customer Purchase Prediction

---

## 📖 Problem Statement:

You are given a dataset of customers with some basic information.  
Your task is to build a Machine Learning model that predicts whether a customer will purchase a product or not.

---

## 🎯 Objective:

Predict the value of the target variable:

- `Purchased` → 
  - 0 = No
  - 1 = Yes

---

## 📊 Dataset Description:

The dataset contains the following columns:

- `Age` → Age of the customer
- `EstimatedSalary` → Salary of the customer
- `Purchased` → Target variable (label)

---

## 📌 Task:

1. Load the dataset
2. Perform necessary preprocessing
3. Train a classification model
4. Evaluate the model using:
   - Confusion Matrix
   - Accuracy
   - Precision
   - Recall
   - F1 Score
5. Make predictions
