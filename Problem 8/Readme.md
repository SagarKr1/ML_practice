## 📌 Problem Title:
Employee Salary Prediction using KNN Regression

---

## 📖 Problem Statement:

You are provided with a dataset containing information about employees, including both numerical and categorical features.

Your task is to build a Machine Learning model using **KNN Regression** to predict the **salary of an employee** based on the given features.

---

## 🎯 Objective:

Predict the target variable:

- **Salary (Continuous Value)**

---

## 📊 Dataset Description:

The dataset contains the following columns:

- **Age** → Age of the employee  
- **Experience** → Years of work experience  
- **Department** → Department of the employee (Categorical)  
- **Position** → Job role (Categorical)  
- **Education** → Education level (Categorical)  
- **Salary** → Target variable  

---

## 📌 Task:
